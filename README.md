\# Groupe 10 - Pipeline d'analyse des fuites de données (HIBP)



Projet Master 1 - Analyse des tendances de data breaches via l'API Have I Been Pwned.



\## Installation



pip install requests



\## Utilisation



python3 hibp\_pipeline.py



Le script télécharge les données depuis l'API HIBP, les sauvegarde en local,

et affiche trois analyses : plus gros breach, évolution par année, types de données volées.
